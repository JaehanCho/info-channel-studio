Info Channel Studio

정보 채널 스튜디오

정보를 전하는 영상 채널을 운영자 한 사람이 직접 관리하려고 만든 개인용 도구입니다. 운영자의 컴퓨터에서만 실행되며, 일반 사용자에게 서비스하지 않습니다.

하는 일
  • 운영자가 만든 영상을 운영자 본인의 YouTube 채널에 올립니다.
  • 업로드할 때마다 운영자가 제목·설명·공개 일정을 직접 확인하고 승인합니다.
  • 올린 뒤에는 업로드가 끝났는지와 공개 예약 상태를 확인합니다.

Google 계정 사용 범위

YouTube 채널에 연결할 때 아래 두 권한만 요청합니다.

  • youtube.upload — 운영자가 승인한 영상을 채널에 올리기
  • youtube.readonly — 연결한 채널이 맞는지, 업로드가 끝났는지 확인하기

자세한 내용은 개인정보처리방침을 보세요.

English

Info Channel Studio is a personal, single-operator tool that runs only on the operator's own computer. It uploads videos the operator has reviewed and approved to the operator's own YouTube channel, and checks upload and scheduling status. It is not offered to the public. See the Privacy Policy.
