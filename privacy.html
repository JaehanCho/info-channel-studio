개인정보처리방침

정보 채널 스튜디오(이하 "이 도구")는 운영자 한 사람이 자기 컴퓨터에서 쓰는 개인용 도구입니다. 이 문서는 이 도구가 Google 계정과 YouTube API로 얻는 정보를 어떻게 다루는지 설명합니다.

1. 받는 정보

  • OAuth 토큰 — 운영자가 동의 화면에서 허용하면 Google이 주는 접근 토큰과 갱신 토큰
  • 채널 정보 — 연결한 YouTube 채널의 ID와 이름, 채널에서 고를 수 있는 동영상 카테고리 목록
  • 업로드 결과 — 이 도구가 올린 영상의 ID, 처리 상태, 공개 예약 상태, 업로드 목록에서 찾은 파일 이름

요청하는 권한은 youtube.upload와 youtube.readonly 두 가지뿐입니다. 다른 사람의 채널, 댓글, 시청 기록, 연락처 같은 정보는 받지 않습니다.

2. 쓰는 목적

  • 운영자가 승인한 영상을 운영자 본인의 채널에 올리기
  • 연결한 채널이 운영자가 정한 채널이 맞는지 확인하기
  • 같은 영상이 두 번 올라가지 않게 업로드 결과를 확인하기

광고, 분석, 프로필 작성, 머신러닝 학습에는 쓰지 않습니다.

3. 저장 위치와 기간

  • 갱신 토큰은 운영자 컴퓨터의 macOS 키체인에만 저장합니다.
  • 채널 정보와 업로드 결과는 운영자 컴퓨터의 로컬 파일에만 저장합니다.
  • 이 도구에는 별도 서버가 없습니다. 운영자 컴퓨터 밖으로 보내는 곳은 Google API뿐입니다.
  • 운영자가 연결을 끊으면 Google에 토큰 폐기를 요청하고, 키체인에서 토큰을 지웁니다.

4. 제3자 제공

Google 사용자 데이터를 판매하거나 제3자에게 제공·공유하지 않습니다.

5. 권한 철회

언제든 Google 계정 › 타사 앱 및 서비스에서 이 도구의 접근 권한을 철회할 수 있습니다. 이 도구 안의 "연결 끊기"로도 같은 일을 합니다.

6. YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 이 도구를 쓰면 YouTube 서비스 약관에 동의하는 것으로 봅니다. Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

7. Google API 서비스 사용자 데이터 정책

이 도구가 Google API로 받은 정보를 쓰고 옮기는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

8. 변경과 문의

이 방침이 바뀌면 이 페이지에 시행일과 함께 올립니다. 문의는 github.com/JaehanCho로 해 주세요.

Privacy Policy

Info Channel Studio ("the tool") is a personal tool used by a single operator on their own computer.

Data we access

  • OAuth access and refresh tokens issued by Google after the operator consents.
  • The connected YouTube channel's ID and title, and the list of assignable video categories.
  • For videos uploaded by the tool: video ID, processing and scheduling status, and file names found in the channel's uploads list.

Requested scopes: youtube.upload and youtube.readonly only.

How we use it

Only to upload videos the operator has approved to the operator's own channel, to confirm the connected channel is the intended one, and to prevent duplicate uploads. Not used for advertising, analytics, profiling, or training machine-learning models.

Storage and retention

The refresh token is stored only in the operator's macOS Keychain; channel and upload records are stored only in local files on the operator's computer. There is no server. Data is sent only to Google APIs. Disconnecting asks Google to revoke the token and deletes it from the Keychain.

Sharing

Google user data is never sold, shared with, or transferred to third parties.

Revoking access

Access can be revoked at any time at Google Account › Third-party apps & services.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
